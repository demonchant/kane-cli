HOSTED STATUS

What is usable today

The supported live workflow today runs locally on your computer: install Kane CLI and Codex CLI, sign into each using its official CLI flow, then start PatchLoop. Your own Kane credits and ChatGPT/Codex plan are used. Follow the repository’s local setup instructions.

The Render blueprint currently has hosted task execution disabled. A public link is not a complete live service until OpenAI approves hosted ChatGPT plan use, Kane and Codex connections are implemented, and per-run isolation and user-owned data storage are in place. No provider credentials are collected here.

Hosting itself can cost the project owner money. Render’s free web service sleeps after inactivity and loses local filesystem changes; the current blueprint uses paid compute and persistent storage. Provider BYO avoids the project paying model/test usage, but it does not make hosting or browser-worker compute free.
